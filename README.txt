# VOID/01 — Experimental Fashion Landing Page

افتح `index.html` مباشرة في المتصفح.

الموقع عبارة عن صفحة Fashion/Streetwear كاملة بستايل سينمائي:
- Hero typography كبيرة
- صور Editorial
- Parallax
- Scroll-driven pinned section
- Hover interactions
- Cursor effect
- Marquee
- Responsive mobile layout
- عداد Bag بسيط

الأنيميشن يعتمد على GSAP + ScrollTrigger من CDN.
