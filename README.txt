VOID/01 — Cinematic Store

تمت إضافة شخصية 3D بصيغة GLB داخل:
assets/character.glb

الموقع يستخدم <model-viewer> من Google CDN لعرض الشخصية على GitHub Pages.
للتشغيل على GitHub:
1) ارفع محتويات هذا المجلد إلى الـrepository.
2) فعّل GitHub Pages من Settings > Pages.
3) اختر branch الرئيسي و /root كمصدر.
