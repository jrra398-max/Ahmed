VOID/01 V3
- Click the wardrobe to open it.
- Collection pieces fall from the wardrobe toward individual hangers.
- Product cards use layered 3D-style garment rendering and small embroidery-like marks.
- Product flow: garment pulled from hanger -> cartoon-styled packing worker -> bag -> ORDER READY -> WhatsApp confirmation.
- WhatsApp opens with a prefilled confirmation message; the customer must press Send.
- True photorealistic 3D requires GLB/GLTF assets; this version uses browser-rendered layered 3D styling without external 3D model files.
