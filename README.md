# NOIR — Virtual Store Prototype

## تشغيل
1. ثبّت Node.js 18+.
2. افتح Terminal داخل المجلد.
3. شغّل:
   npm install
   npm run dev

## الموجود في النسخة
- Cinematic neon intro.
- Enter the Store / View Collection.
- 3D virtual store باستخدام Three.js.
- Racks قابلة للاختيار.
- Product panel مع تنقل بين المنتجات.
- Add to Bag.
- Bag + total.
- Cashier cinematic box.
- WhatsApp confirmation كـDemo فقط.
- Sound toggle UI.
- Responsive mobile layout.

## ملاحظات
هذه Prototype واجهة وتجربة، وليست نسخة Production.
لا يوجد Backend أو قاعدة بيانات أو WhatsApp API حقيقي.
الـ3D shirts الحالية placeholders، وسيتم استبدالها بملفات GLB/GLTF حقيقية للملابس.
